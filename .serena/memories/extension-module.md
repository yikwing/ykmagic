# 扩展模块 (module_extension)

## 目录结构
```
module_extension/src/main/java/com/yikwing/extension/
├── activity/      # Activity 扩展
├── app/           # Application 扩展
├── collection/    # 集合扩展
├── coroutines/    # 协程扩展
├── date/          # 日期扩展
├── delegate/      # 委托扩展
├── image/         # 图片扩展
├── io/            # IO 扩展
├── json/          # JSON 扩展
├── network/       # 网络扩展
├── util/          # 工具扩展
├── view/          # View 扩展
├── GlobalContextProvider.kt
└── ExtensionInitProvider.kt
```
